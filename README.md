# Arma 3 NPC 對話管理系統 (Dialogue Manager)

這是一個專為 **Arma 3** 任務編作者設計的工具。透過網頁介面視覺化編輯 NPC 對話，並自動產出對應的 `.sqf` 腳本。

## 📂 專案結構
- **.venv/**: Python 虛擬環境資料夾。
- **input/**: 存放所有對話的原始資料 (JSON 格式)。
- **output/**: 存放產出的 SQF 檔案空間。
- **static/**: 網頁靜態資源，包含 CSS 樣式與前端 JS 邏輯。
- **templates/**: 存放 HTML 網頁模板。
- **app.py**: Flask 後端伺服器程式。
- **spawner.py**: 負責將資料轉換為 Arma 3 腳本的核心邏輯。
- **requirements.txt**: 紀錄專案所需的所有 Python 套件。

## 🚀 快速安裝與啟動

1. **環境準備**：
   建議使用虛擬環境 (venv)：
   
   ```python -m venv .venv```
   
   # 啟動虛擬環境 (Windows)
   ```.venv\Scripts\activate```

2. **安裝依賴**：
   
   ```pip install -r requirements.txt```

3. **啟動程式**：
   
   python app.py
   
   啟動後，開啟瀏覽器訪問 http://127.0.0.1:5000。

## 🛠️ 操作流程

### 1. 編輯對話
* 在網頁左側輸入 **NPC ID**（即存檔檔名）與基礎資訊（姓名、動作文字、開場白）。
* 使用中間區域新增對話選項，填寫玩家說的話與 NPC 的回應。
* 系統會根據字數自動計算字幕顯示時間，確保玩家有足夠時間閱讀。

### 2. 管理存檔
* **💾 儲存 JSON**：將設定存入 input/。若偵測到同名檔案，系統會彈出覆蓋警告。
* **🗑️ 刪除檔案**：點擊左側列表中的 × 即可移除舊存檔。
* **🧹 清空內容**：一鍵重設所有欄位，快速開始編寫下一個 NPC。

### 3. 套用至遊戲
* **📋 複製 SQF**：點擊後腳本將直接複製到剪貼簿，無需手動開啟檔案。
* **遊戲內設定**：在 Arma 3 編輯器中，將複製的代碼貼入 NPC 單位的 Initialization (初始化) 欄位即可。

## 💡 技術重點
* **自動時長計算**：確保字幕停留時間符合語速節奏。
* **動態陣營配色**：腳本會自動偵測 NPC 陣營（西、東、游擊、平民）並給予對應的字幕名稱顏色。
* **距離中斷機制**：玩家離開 NPC 超過 5 公尺時會自動關閉選單，防止邏輯卡死。
