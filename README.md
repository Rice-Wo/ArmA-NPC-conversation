# Arma 3 NPC 對話管理系統 (Dialogue Manager)

可以自動生成NPC對話的sqf(arma3 腳本)
此項專案除原腳本外，其餘皆為Gemini生成

## 使用方式

填寫完內容後複製，並在單位的腳本欄中貼上，要注意執行區域必須選G(全域)
